## 🚀 Installation Methods

### Method 1: ZIP Upload (Easiest - 2 minutes)
1. Zip the `shopify-theme` folder
2. Shopify Admin → Online Store → Themes
3. Add theme → Upload ZIP
4. Publish!

### Method 2: Theme Kit (For Developers)
```bash
cd shopify-theme
theme configure --password=YOUR_API_PASSWORD --store=yourstore.myshopify.com
theme deploy
```

### Method 3: GitHub
1. Push to GitHub
2. Connect GitHub to Shopify
3. Import theme
